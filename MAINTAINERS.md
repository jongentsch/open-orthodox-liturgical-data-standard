# Maintainers

## Bootstrap technical maintainer

- Jon Gentsch (`@jongentsch`)

The bootstrap maintainer administers the repository, accepts technical changes,
records consequential decisions as ADRs, and coordinates external review. This
role does not confer ecclesiastical authority and cannot make a conforming pack
ecclesiastically endorsed.

Before normative schemas are approved, the project will seek independent
liturgical/domain and implementation reviewers as described in
[GOVERNANCE.md](docs/GOVERNANCE.md).
