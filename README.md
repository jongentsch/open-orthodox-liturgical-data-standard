# Open Orthodox Liturgical Data Standard

The Open Orthodox Liturgical Data Standard (OOLDS, a provisional name) is an
open interchange project for Orthodox liturgical data. Its intended scope is
stable identity, distinct observances, scoped claims, calendar-rule inputs,
lection appointments, multilingual labels, provenance, rights, and portable
offline data packs.

OOLDS is not a universal Typikon and will not prescribe how a church resolves
rank, precedence, collisions, transfers, fasting, or service assembly. Those
are engine and policy concerns. OOLDS should make the inputs, disagreements,
sources, and resulting projections exchangeable without silently flattening
them.

## Project status

This repository is at **research foundation / pre-v0.1**. The architecture has
been accepted as the working Phase 2 hypothesis, but there is no normative
schema, registry, reference implementation, or endorsed dataset yet. That is a
deliberate constraint: the domain model and project boundary must survive
external review before syntax becomes a compatibility promise.

The first research pass found useful prior art in Ponomar, Orthocal,
typikon-engine and its jurisdiction packs, the GOARCH Digital Chant Stand,
Ispovednik, OCA and Antiochian calendar/service sources, and Church Slavonic
corpora. None presently provides the complete neutral interchange layer this
project proposes. See [Prior art](docs/PRIOR-ART.md) for the evidence and the
limits of that conclusion.

## Proposed interoperability layers

1. **Identity layer:** stable identifiers for subjects, observances, works,
   expressions, sources, authorities, and vocabulary terms.
2. **Assertion layer:** scoped claims with explicit context, evidence,
   attribution, status, and validity.
3. **Pack layer:** versioned offline distributions with namespace ownership,
   dependencies, checksums, and per-resource rights.
4. **Projection layer:** dated calendars, feeds, and service plans generated by
   engines. Projections are outputs, not canonical source records.
