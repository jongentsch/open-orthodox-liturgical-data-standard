# Decision 0002: accept the domain architecture as a working hypothesis

- Status: accepted for Phase 2
- Date: 2026-08-24

## Decision

OOLDS will proceed with the entity → observance → typed scoped claim model,
supported by separate context, evidence/source, agent/authority-role, validity,
and rights concepts.

Identity mappings are claims rather than unconditional facts. Rank, fasting,
tone, date, naming, reception, and lection appointments remain contextual. A
Typikon engine consumes these inputs and resolves precedence, collisions,
transfers, fasting interactions, and service assembly outside the OOLDS core.

## Status of the model

This accepts a working hypothesis, not a normative schema. Phase 2 domain review
and Phase 3 adversarial fixtures may revise terms, cardinalities, and extension
boundaries without a compatibility obligation.

## Consequences

- Schema implementation remains gated.
- Generic loaders must parse identity and claims without jurisdiction-specific
  branches.
- Engine outputs remain traceable projections rather than canonical source
  records.
- Failure of a real case changes the model instead of creating an undocumented
  exception.
