# Decision 0003: adopt a multi-license policy

- Status: accepted
- Date: 2026-08-24

## Decision

OOLDS uses:

- Apache-2.0 for software, schemas, and executable tooling;
- CC BY 4.0 for specification prose, documentation, diagrams, and authored
  examples;
- CC0-1.0 for original factual reference data and factual conformance fixtures
  explicitly marked as OOLDS reference data.

Third-party resources retain their own rights and require resource-level
notices. Unknown rights never imply permission to redistribute content.

The project's noncommercial, Church-serving character is a mission statement,
not a field-of-use restriction.

## Consequences

- Contributions use the applicable category unless a different notice is
  explicitly accepted.
- Packs can combine factual OOLDS reference data with separately licensed or
  reference-only content.
- Releases need an auditable third-party and exceptions inventory.
