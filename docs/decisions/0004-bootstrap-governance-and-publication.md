# Decision 0004: bootstrap governance and personal-repository publication

- Status: accepted
- Date: 2026-08-24

## Decision

Jon Gentsch (`@jongentsch`) is the initial technical maintainer. Consequential
architectural changes use ADRs. Normative schemas require external liturgical
and technical review, and conformance does not imply ecclesiastical endorsement.

The project will begin as a public repository under the maintainer's personal
GitHub account. It may transfer to an organization when shared governance and
additional maintainers make that useful.

## Consequences

- Bootstrap decisions can proceed without inventing a committee.
- Domain authority remains distinct from repository administration.
- Governance must mature before a multi-maintainer normative release.
